# FX Hedging

This capability evaluates foreign exchange (FX) hedging strategies and compares their effects on a company's USD cash flows.

## Project Stages

- **Stage 1 — Executive Brief:** Define the currency exposure, quantify the risk, and establish assumptions and a hypothesis.
- **Stage 2 — Model Specification:** Document the workbook structure, named ranges, formulas, and validation checks in `spec.md`.
- **Stage 3 — AI-Assisted Build + Audit:** Build the Excel workbook in `model.xlsx` and document the build audit.
- **Stage 4 — Market Data + Population:** Populate the workbook with sourced, timestamped market data.
- **Stage 5 — Validation + Decision Memo:** Independently validate the model and document the final hedge recommendation.

## Files

- `README.md` — Overview of this capability and its project stages.
- `spec.md` — Stage 2 model specification.
- `model.xlsx` — Workbook developed in Stages 3 and 4.
