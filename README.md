## Finance Project: FX Hedging Analysis

### Scenario 33 — Mining Shovels

An FX hedging analysis evaluating strategies for a EUR 14.5 million receivable due in 182 days. The project applies financial modeling, market-data research, independent validation, and treasury decision-making to compare unhedged exposure, forward contracts, money-market hedges, and currency options.

**Project stages and deliverables**

| Stage | Deliverable |
|---|---|
| Stage 1 | Project setup and repository structure |
| Stage 2 | [Technical specification](capabilities/fx-hedging/spec.md) |
| Stage 3 | [Excel hedging model](capabilities/fx-hedging/model.xlsx) and [build audit](analysis/2026-11-24-scenario-33-validation-analysis.md) |
| Stage 4 | [Market-data memo](data/2026-11-18-scenario-33-market-data-memo.md) |
| Stage 5 | [Independent LLM output](analysis/2026-11-24-scenario-33-independent-llm-output.md), [validation analysis](analysis/2026-11-24-scenario-33-validation-analysis.md), and [CFO decision memo](docs/decisions/2026-11-24-scenario-33-hedge-decision-memo.md) |

**Core analysis:** Forward hedge, money-market hedge, put and call options, covered interest-rate parity, sensitivity analysis, and hedge recommendation.

**Tools:** Excel, financial modeling, market-data research, GitHub, and AI-assisted validation.
